# OpenTelemetry zero-code instrumentation. The `opentelemetry-instrument` launcher patches
# httpx to propagate W3C traceparent on outbound calls — including the orchestrator's A2A
# calls — so the whole multi-agent flow lands in ONE trace instead of three disconnected ones.
#
# opentelemetry-distro sets OTEL_TRACES_EXPORTER=otlp but bundles no OTLP exporter, so the
# HTTP one must be installed explicitly or the launcher crashes with "otlp_proto_grpc not
# found". Paired with OTEL_EXPORTER_OTLP_PROTOCOL=http/protobuf in the Dockerfiles.

opentelemetry-exporter-otlp-proto-http
opentelemetry-instrumentation-httpx
opentelemetry-instrumentation-fastapi
